# Synthetic Data Generator 🧬

Платформа для генерации синтетических данных с использованием локальных языковых моделей (LLM). Проект позволяет развернуть полноценное веб-приложение для создания реалистичных датасетов без отправки данных на внешние API.

## 🏗 Архитектура

Проект состоит из трех основных компонентов:

* **Frontend**: React/Next.js приложение для управления генерацией.
* **Backend**: FastAPI сервис для обработки запросов и логики.
* **Worker**: Фоновые задачи (Celery) для тяжелых вычислений и взаимодействия с LLM.
* **Infrastructure**: Docker Compose для быстрой развертки всех сервисов.

---

## 🛠 Предварительные требования

Перед запуском убедитесь, что у вас установлены:

1. **Docker** и **Docker Compose**.
2. **Ollama** (для запуска локальных моделей).

### Шаг 1: Подготовка локальной модели (Ollama)

Для работы сайта необходимо скачать и запустить модель локально:

1. Установите Ollama с [официального сайта](https://ollama.com/).
2. Запустите загрузку модели (например, Llama 3):
```bash
ollama run llama3

```


*Убедитесь, что Ollama запущена и доступна по адресу `http://localhost:11434`.*

---

## 🚀 Запуск проекта

### 1. Настройка окружения

Создайте файл `.env` в корневой директории и укажите необходимые переменные (базы данных, пути к API Ollama).

### 2. Запуск через Docker Compose

Самый простой способ поднять все сервисы сразу:

```bash
docker-compose up --build

```

Это запустит:

* Веб-интерфейс на `http://localhost:3000`
* API бэкенда на `http://localhost:8000`
* Воркеры для генерации данных

---

## 📖 Как пользоваться сайтом

1. **Подключение модели**: Убедитесь, что в настройках профиля или в конфиге указано использование локальной Llama.
2. **Создание задачи**: Опишите структуру данных, которую вы хотите получить (схема JSON или описание колонок).
3. **Генерация**: Нажмите кнопку "Generate". Воркер подхватит задачу, обратится к локальной модели и начнет наполнять таблицу.
4. **Экспорт**: Скачайте полученные синтетические данные в формате CSV или JSON.

## 📂 Структура репозитория

* `/backend` — Логика приложения, API эндпоинты.
* `/frontend` — Интерфейс пользователя.
* `/worker` — Обработка очередей и интеграция с LLM.
* `docker-compose.yml` — Описание конфигурации всей системы.

## 🧪 Разработка (локально)

Если вы хотите запустить сервисы по отдельности без Docker:

**Backend:**

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload

```

**Frontend:**

```bash
cd frontend
npm install
npm run dev

```
